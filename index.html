Auto Guesser

Code Demo

A 20 Questions game for cars. You think of a vehicle and it asks questions until it makes a final guess. A Naive Bayes model picks the question that best splits the remaining candidates each turn. It covers 100+ vehicles across 60+ attributes, and players can add new cars, so the database grows as people use it. Currently the model is able to make final guesses on average by the 12th question depending on how niche the vehicle model is. Caching Wikimedia images in the database cut load times by about 15%.

Job Salary Data Analysis & Predictor

Code Demo

A project exploring the current tech job market in terms of salary. Analysis was based on 250,000 job postings and identified location and job title as the strongest salary predictors. Dataset was used to train a Random Forest Regression model achieving R² of 0.969 and MAE of $5,171 on 250,000 records. Findings were presented through a three page Power BI dashboard including visualizations of trends.
